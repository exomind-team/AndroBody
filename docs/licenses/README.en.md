# Third-party licenses

AndroBody has not declared a project-wide software license. Each dependency retains its own terms.

`native-runtime-dependencies-2026-10-28.json` is a dated inventory of resolved Android runtime artifacts and the license metadata available for that build snapshot. It is not a grant to reuse AndroBody source, nor a guarantee that later dependency graphs are identical. Recheck the resolved graph and notices before distributing a different build.

The CommonMark Java BSD-2-Clause notice is retained in `commonmark-java-0.30.0-LICENSE.txt`. AndroidX, Kotlin, OkHttp, and other dependencies remain under their upstream licenses. Missing metadata is unknown; it is not interpreted as permission or as evidence that no license applies.
