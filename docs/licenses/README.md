# Third-party licenses

**Language** · [简体中文](README.md) · [English](README.en.md)

AndroBody has no project-wide software license declaration. Each dependency retains its own terms.

`native-runtime-dependencies-2026-10-28.json` is a dated inventory of resolved Android runtime artifacts and the license metadata available for that build snapshot. It is not a grant to reuse AndroBody source, and it is not a guarantee that later dependency graphs are identical. Recheck the resolved graph and notices before distributing a different build.

The CommonMark Java BSD-2-Clause notice is retained in `commonmark-java-0.30.0-LICENSE.txt`. AndroidX, Kotlin, OkHttp and other dependencies retain their upstream licenses as identified by their published artifacts. Missing metadata remains unknown; it is not interpreted as permission or as an assertion that no license applies.
